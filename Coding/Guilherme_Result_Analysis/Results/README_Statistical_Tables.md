# Statistical Tables — Data Dictionary

Generated by `scripts/generate_statistical_tables.py` from
`results/cultural_prompting/RQ2_CP_Responses_L2_Results.csv`.

---

## Context

These tables are part of a dissertation evaluating cultural bias in large language
models (LLMs) using the World Values Survey (WVS) framework.

The core metric is the **L2 distance** between a model's position and a country's
human-survey position on the Inglehart-Welzel Cultural Map (two-dimensional PCA
space: *Survival vs. Self-Expression* × *Traditional vs. Secular* values).

Two conditions are compared throughout:

- **L2_C** ("C" for *control*) — distance without cultural prompting: the model
  responds as a generic agent, with no country-specific instruction.
- **L2_A** ("A" for *alignment*) — distance with cultural prompting: the model is
  instructed to respond as a person from a specific country.

A smaller L2 distance means the model's cultural profile is closer to the human
survey data for that country.

Models evaluated: GPT-3, GPT-3.5-turbo, GPT-4, GPT-4-turbo, GPT-4o,
GPT-5.6-terra, GPT-6-astra.

## File 1: `Statistical_Analysis_PerModel_CvsA.csv`

**One row per model (7 rows total).**

Answers: *"Does cultural prompting significantly reduce a model's cultural distance
from humans?"*

| Column | Description |
|---|---|
| `model` | GPT model name |
| `n_paired` | Number of countries with valid data for both conditions simultaneously. GPT-3.5-turbo has 106 (one country with missing values was excluded); all others have 107 |
| `mean_L2_C` | Mean L2 distance across all countries **without** cultural prompting. Represents the model's average cultural bias in its default state |
| `median_L2_C` | Median L2 distance without prompting. If notably lower than the mean, a few countries with very high distances are skewing the average |
| `sd_L2_C` | Standard deviation of L2_C. Indicates whether the model is uniformly biased across all countries or highly variable (e.g., close to some cultures, far from others) |
| `min_L2_C` | Smallest L2_C observed — the country whose cultural profile is closest to the model's default |
| `max_L2_C` | Largest L2_C observed — the country culturally furthest from the model's default |
| `shapiro_W_C` | Shapiro-Wilk W statistic for the L2_C distribution. Ranges from 0 to 1; values close to 1 indicate normality |
| `shapiro_p_C` | Shapiro-Wilk p-value for L2_C. p < 0.05 indicates a **non-normal** distribution. All models fail normality in the no-prompting condition, reflecting asymmetric distance distributions |
| `normal_C` | Shorthand flag: is L2_C normally distributed? (`yes`/`no`). All models: `no` |
| `mean_L2_A` | Mean L2 distance across all countries **with** cultural prompting. Measures how close the model gets to each country's human profile when instructed to adopt that country's perspective |
| `median_L2_A` | Median L2 distance with prompting |
| `sd_L2_A` | Standard deviation of L2_A. Generally lower than `sd_L2_C`, indicating that prompting not only reduces distances but also makes them more uniform across countries |
| `min_L2_A` | Smallest L2_A observed |
| `max_L2_A` | Largest L2_A observed |
| `shapiro_W_A` | Shapiro-Wilk W statistic for the L2_A distribution |
| `shapiro_p_A` | Shapiro-Wilk p-value for L2_A. GPT-4 and later models pass normality with prompting (p > 0.05), suggesting prompting regularises the model's cultural behaviour |
| `normal_A` | Shorthand flag: is L2_A normally distributed? (`yes`/`no`). GPT-4 and newer: `yes`; GPT-3 and GPT-3.5-turbo: `no` |
| `mean_diff_C_minus_A` | Difference of means (L2_C − L2_A). **Positive values** indicate prompting **reduced** cultural distance; larger values indicate greater alignment gains. GPT-5.6-terra (≈ 1.88) and GPT-6-astra (≈ 1.99) show the highest gains |
| `wilcoxon_V` | V statistic of the paired Wilcoxon signed-rank test. Very low values (e.g., 117 for GPT-6-astra) indicate that nearly all countries show a reduction in distance under prompting |
| `wilcoxon_p` | P-value of the Wilcoxon test. Answers: *"Is the reduction in distance with prompting statistically significant?"* All models: p << 0.05 |
| `significant_p05` | Shorthand flag: is the Wilcoxon result significant at α = 0.05? All models: `yes` |

## File 2: `Statistical_Analysis_Pairwise_Wilcoxon.csv`

**42 rows (21 model pairs × 2 conditions).**

Answers: *"Is there a statistically significant difference in cultural distance
between two distinct models, within the same condition?"*

| Column | Description |
|---|---|
| `condition` | The condition being compared: `Without_Cultural_Prompting` (compares L2_C of the two models) or `With_Cultural_Prompting` (compares L2_A of the two models) |
| `model_1` | First model in the pair |
| `model_2` | Second model in the pair |
| `n_paired` | Number of countries with valid data for both models simultaneously |
| `wilcoxon_V` | V statistic of the Wilcoxon signed-rank test. For each country, the test compares the distance of model_1 against model_2; V summarises the direction and magnitude of differences across all countries |
| `p_value` | Raw p-value. Example: GPT-3 vs GPT-4o without prompting: p = 0.12 → no significant difference between those two models in that condition |
| `p_adjusted` | Bonferroni-corrected p-value (raw p × number of tests per condition = 21). Accounts for multiple comparisons — a pair may be significant on the raw p but not after correction |
| `significant_p05` | Shorthand flag: significant **without** correction at α = 0.05? (`yes`/`no`) |
| `significant_adj_p05` | Shorthand flag: significant **with** Bonferroni correction at α = 0.05? This is the more conservative, recommended criterion for inference |

## File 3: `Consolidated_L2_All_Models_by_Country.csv`

**107 rows (one per country/territory), 22 columns.**

The granular reference table. Enables comparison across models within the same
country, and identification of countries where prompting helped or failed.

| Column | Description |
|---|---|
| `country.territory` | Country or territory name, as coded in the WVS dataset |
| `[Model]_L2_C` | L2 distance between that model and the human-survey coordinates of this country **without** cultural prompting. Example: `GPT4_L2_C` = 3.69 for Algeria means GPT-4 (no prompting) is 3.69 units away from Algeria's human cultural position on the map |
| `[Model]_L2_A` | Same distance **with** cultural prompting — after instructing the model to respond as a person from this country |
| `[Model]_diff_C_minus_A` | L2_C − L2_A for this country and model. **Positive**: prompting brought the model closer to this country's culture. **Negative**: prompting moved the model *further away* — the model's imitation of that culture was worse than its default. Andorra, for instance, shows negative values across several models, suggesting its cultural profile is atypical and difficult to capture via simple prompting |

Model name abbreviations used in column prefixes:

| Prefix | Full model name |
|---|---|
| `GPT3` | GPT-3 |
| `GPT35Turbo` | GPT-3.5-turbo |
| `GPT4` | GPT-4 |
| `GPT4Turbo` | GPT-4-turbo |
| `GPT4o` | GPT-4o |
| `GPT56Terra` | GPT-5.6-terra |
| `GPT6Astra` | GPT-6-astra |

## Notes

- All Wilcoxon tests are **two-sided** and **paired by country**.
- Normality was assessed with Shapiro-Wilk (n = 107; recommended for n < 2000).
- Multiple comparison correction uses **Bonferroni** (conservative), consistent
  with the pilot study tables already in the project.
- The script that generated these files is fully reproducible:
  `scripts/generate_statistical_tables.py`.
